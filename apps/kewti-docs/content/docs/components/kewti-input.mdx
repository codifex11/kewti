## Features

- Toggle between **Amharic** and **English** input.
- Real-time **Amharic transliteration** from Latin characters.
- Multiple transliteration suggestions and homophone support.
- Built-in **Amharic spell checking** via `KewtiSpell`.
- Built-in voice dictation.
- Supports both **input** and **textarea** variants.
- Auto-resizing textarea.
- Controlled and uncontrolled modes.
- Compatible with React Hook Form and other form libraries.
- Keyboard shortcuts for fast typing.

## How to Write (Amharic Transliteration)

When Amharic mode is active, Latin keystrokes are automatically converted into Ge'ez script (Fidel). 

### 1. Vowel Order Modifications

Type a consonant key followed by a vowel to change the **Fidel order**:

| Fidel Order | Modifying Key | Example (`b` + Key) | Output |
| :--- | :--- | :--- | :--- |
| **1st Order (G'eez)** | `e` | `b` + `e` | **በ** |
| **2nd Order (Ka'ib)** | `u` / `oo` | `b` + `u` | **ቡ** |
| **3rd Order (Salis)** | `i` | `b` + `i` | **ቢ** |
| **4th Order (Rabi)** | `a` / `aa` | `b` + `a` | **ባ** |
| **5th Order (Hamis)** | `ee` / `ie` | `b` + `ee` | **ቤ** |
| **6th Order (Sadis)** | *(Default / Consonant only)* | `b` | **ብ** |
| **7th Order (Sabi)** | `o` | `b` + `o` | **ቦ** |
| **8th Order (Labialized)** | `wa` | `b` + `wa` | **ቧ** |

### 3. Typing Rules

* **Digraphs**: Standard multi-character letter combinations are recognized automatically:
  - `sh` → **ሽ** (or `she` → **ሸ**)
  - `ch` → **ች** (or `che` → **ቸ**)
  - `zh` → **ዥ** (or `zhe` → **ዠ**)
  - `ny` / `gn` → **ኝ** (or `nye` / `gne` → **ኘ**)
  - `ts` → **ጽ** (or `tse` → **ጸ**)
  - `kh` → **ኽ** (or `khe` → **ኸ**)
  - `ph` → **ጵ** (or `pha` → **ጳ**)
  - `hh` → **ሕ** (or `hhe` → **ሐ**)
* **Standalone Vowels**: Vowels typed without a preceding consonant produce the corresponding glottal-stop Fidel characters (e.g. `a` → **አ**, `e` → **እ**, `i` → **ኢ**, `o` → **ኦ**, `u` → **ኡ**), with alternatives (such as **ዐ**, **ዒ**, **ዖ**) in suggestions. Standalone `e` yields 6th-order **እ** to match natural transliteration (e.g. *emebet* → **እመቤት**), whereas consonant + `e` modifies to 1st order (e.g. `be` → **በ**); 1st-order **አ** is also available in suggestions for `e`.
* **Labialization (`wa`)**: Typing a consonant followed by `wa` yields the 8th-order labialized Fidel character (e.g. `kwa` → **ኳ**, `qwa` → **ቋ**, `gwa` → **ጓ**, `twa` → **ቷ**, `bwa` → **ቧ**). Consonants without a labialized glyph fall back deterministically (e.g. `wwa` → **ውዋ**, `ywa` → **ይዋ**).
* **Escape Hatch (`'` or `_`)**: Separate letters to prevent automatic digraph or gemination merging (e.g. `s'h` → **ስህ**, `s'he` → **ስሀ**, `s'se` → **ስሰ**).
* **Initial Capitalization**: Word-initial capitals (`Ch`, `Sh`, `T`, `S`, `H`, `C`, `P`) map to the base consonant (primary in 6th order: **ች**, **ሽ**, **ት**, **ስ**, **ህ**, **ች**, **ፕ**) rather than emphatics to protect capitalized names and sentence starts (e.g. `Selam` → **ሰላም**, `Tadesse` → **ታደሰ**, `Te` / `TE` → **ተ**, `Ca` → **ቻ**), with emphatic forms available in suggestions. Mid-word capitals retain SERA emphatics (e.g. `aTe` → **አጠ**).
* **All-Caps (Caps Lock)**: Typing words in all-caps (e.g. `TESFAYE`, `SELAM`, `TE`, `GEMED`) treats the input as Caps Lock and lowercases it before transliterating, avoiding unintended emphatic substitutions.
* **Gemination**: Repeated identical English consonants before a vowel are automatically merged into a single consonant (e.g. `Tadesse` → **ታደሰ**, `Addis` → **አዲስ**). Consecutive consonants without a vowel produce separate 6th-order syllables (e.g. `ss` → **ስስ**).

---

### 4. Punctuation Mappings

| Key | Amharic Punctuation | Name |
| :---: | :---: | :--- |
| `.` | **።** | Arat Neteb (Full Stop) |
| `,` | **፣** | Comma |
| `;` | **፤** | Semicolon |
| `:` | **፥** | Hulet Neteb (Colon) |

---

### 5. Homophones & Phonetic Variants

Some letters in Amharic share identical or similar pronunciations. When typing these characters, `KewtiInput` automatically presents alternative homophones in the suggestion menu:

* **Ha variants**: `ሀ` ↔ `ሐ` ↔ `ኅ`
* **Se variants**: `ሰ` ↔ `ሠ`
* **Tse variants**: `ጸ` ↔ `ፀ`
* **A variants**: `አ` ↔ `ዐ`

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Space` | Accept the selected transliteration |
| `← → ↑ ↓` | Navigate transliteration suggestions |
| `Enter` | Accept suggestion (when suggestions are visible) |
| `Enter` | Send message (when no suggestions are visible) |
| `Shift + Enter` | Insert a new line (textarea only) |

---

## Voice Dictation

Click the microphone icon to start dictation.

- Uses the browser's Speech Recognition API.
- Dictation language is **Amharic (`am-ET`)**.
- Speech is appended to the existing input.
- Recording can be stopped at any time.

If speech recognition isn't supported by the browser, the microphone button is automatically hidden.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"input" \| "textarea"` | `"input"` | Input variant to render. |
| `value` | `string` | — | Controlled value. |
| `onValueChange` | `(value: string) => void` | — | Called whenever the value changes. Recommended for controlled state. |
| `onChange` | `ChangeEventHandler<HTMLInputElement \| HTMLTextAreaElement>` | — | Standard React change event. |
| `onSend` | `(value: string) => void` | — | Called when Enter is pressed (or Enter without Shift in textarea). |
| `defaultLanguage` | `"am" \| "en"` | `"am"` | Initial input language. |
| `placeholder` | `string` | — | Placeholder text. |
| `spellCheck` | `boolean` | `false` | When `true`, enables Amharic spell checking via `KewtiSpell`. |
| `showVoiceInput` | `boolean` | `false` | Shows or hides the voice input button. |
| `disabled` | `boolean` | `false` | Disables editing, language switching, and voice input. |
| `className` | `string` | — | Additional classes for the outer container. |
| `inputClassName` | `string` | — | Additional classes for the input or textarea. |
| `style` | `React.CSSProperties` | — | Inline styles for the container. |
| `onKeyDown` | `KeyboardEventHandler` | — | Custom keyboard event handler. |

All standard HTML input or textarea props are also supported.

## Browser Support

Voice dictation relies on the browser's Speech Recognition API (`SpeechRecognition` or `webkitSpeechRecognition`).

Supported browsers include:

- Chrome
- Microsoft Edge
- Other Chromium-based browsers

Browsers without speech recognition support automatically hide the microphone button.
