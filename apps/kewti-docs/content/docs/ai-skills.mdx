Kewti supports AI coding assistants out of the box. By installing the Kewti AI skill into your repository, your AI pair programmer (Antigravity, Cursor, GitHub Copilot, Claude, OpenAI Codex, Windsurf) can use Kewti to create Ethiopian calendars, time pickers, Ge'ez numerals, phonetic inputs, and localized UI components.

---

## Quick Start: Install AI Skill

Run the `skill` command directly in your project root:

```bash
# Auto-configure for all AI agents (Antigravity, Cursor, Copilot, Claude, Codex)
npx kewti-cli skill
```

You can also target your specific AI agent or editor:

```bash
# For Antigravity / Agentic IDEs (.agents/skills/kewti/)
npx kewti-cli skill antigravity

# For Cursor AI (.cursorrules and .cursor/rules/kewti.mdc)
npx kewti-cli skill cursor

# For GitHub Copilot (.github/copilot-instructions.md)
npx kewti-cli skill copilot

# For Claude & Universal Agents (CLAUDE.md and AGENTS.md)
npx kewti-cli skill claude

# For OpenAI Codex / Codex CLI (CODEX.md)
npx kewti-cli skill codex
```

### Preview Changes (`--dry-run`)

To see what files will be created without modifying your codebase:

```bash
npx kewti-cli skill --dry-run
```

## What Your AI Agent Learns

When the Kewti skill is installed, your AI agent automatically adheres to these critical domain rules and APIs:

| Domain | What the AI Learns | Example Prompt |
| :--- | :--- | :--- |
| **Ethiopian Calendar** | 13 months, `Kenat` date calculations, Pagume leap years, holiday highlights. | *"Create a hotel booking form with an Ethiopian calendar picker"* |
| **Ethiopian Time** | Sunrise 06:00 AM Gregorian = 12:00 ጠዋት (morning), 12-hour cyclical time offsets (`tewat`, `keseat`, `mishit`, `lelit`). | *"Build an Ethiopian flight departure time selector"* |
| **Phonetic Typing** | Latin-to-Ge'ez transliteration, voice dictation, Kebele ID and TIN format masks. | *"Add a customer search input that allows typing in Amharic phonetically"* |
| **Ge'ez Numerals** | Arabic to Ge'ez (`፩`, `፪`, `፲`) numeral conversion, spelled-out Birr and Santim words. | *"Format invoice total in Ge'ez numerals and Amharic words"* |
| **Locations** | Cascading Region (Admin 1), Zone/Subcity (Admin 2), and Woreda (Admin 3) selectors. | *"Create an Ethiopian delivery address form"* |
| **Brand Logos** | Over 70+ vector brand icons (Commercial Bank of Ethiopia, Telebirr, Awash, Chapa, Ethiopian Airlines). | *"Add a payment methods section with CBE Birr, Telebirr, and Chapa logos"* |

## Supported AI Environments

### 1. Antigravity & Agentic IDEs
Generates a complete Antigravity skill package under `.agents/skills/kewti/`:
- `SKILL.md`: Skill definition with semantic triggers and quick reference table.
- `references/calendar.md`: Comprehensive Ethiopian calendar specs and `Kenat` recipes.
- `references/time.md`: Deep dive on Ethiopian solar time calculations and conversions.
- `references/inputs-and-spell.md`: Phonetic key mapping rules and fuzzy spellchecking.
- `references/numerals-and-locations.md`: Ge'ez numbers and cascading dropdown patterns.
- `references/fonts-and-logos.md`: Ethiopic font loaders and vector brand icon catalog.
- `references/cli.md`: CLI programmatic automation reference.

### 2. Cursor AI
Generates `.cursorrules` and `.cursor/rules/kewti.mdc` enforcing:
- Immediate component imports from `@/kewti/ui`.
- Mandatory `"use client"` directives on interactive components.
- Prevention of custom ad-hoc Ethiopian leap year formulas in favor of `Kenat`.

### 3. GitHub Copilot
Generates `.github/copilot-instructions.md` ensuring inline tab completions follow:
- Tailwind CSS dark mode utilities.
- Ethiopian time conversion math (`stdToEth` and `ethToStd24`).
- Standardized prop interfaces for Kewti components.

### 4. Claude & Universal Coding Agents
Generates `CLAUDE.md` and `AGENTS.md` containing architectural context and CLI commands.

### 5. OpenAI Codex & Codex CLI
Generates `CODEX.md` instructing Codex on:
- Immediate component imports from `@/kewti/ui` or `@/kewti/ui/<component>/component`.
- Mandatory `"use client"` directive on interactive components.
- Strict use of `Kenat` (`import Kenat from "kenat"`) for 13-month calendar logic.
- Ethiopian 6-hour offset solar time calculation (`stdToEth`, `ethToStd24`).
- CLI installation commands and zero-shot code generation examples.

## Machine-Readable AI Discovery

AI models and scripts can inspect available Kewti components, dependencies, and code snippets directly through the CLI using JSON output:

```bash
# List all available components, fonts, and logos as JSON
npx kewti-cli list --json

# Inspect component dependencies and copy-paste React snippet as JSON
npx kewti-cli info calendar --json
npx kewti-cli info time --json
npx kewti-cli info skill --json
```

## `llms.txt` Standard

Kewti docs natively implements the `/llms.txt` standard for AI document ingestion:
- **Index (`/llms.txt`):** Concise summary and URL map for AI web scrapers.
- **Full Reference (`/llms-full.txt`):** Complete, zero-shot documentation with full TypeScript prop interfaces and copy-paste examples in a single fetchable file.
